# 경주시 공공데이터 AI 업무도우미

**2026년 공공 AI 대전환 챌린지 — 행정업무 효율화 출품 준비 소스**

공공데이터 등록 업무에서 CSV를 분석해 메타데이터와 등록용 Excel을 작성하도록 지원하는 **AI 웹 도구**와, 내부망 포털에서 입력·CSV 첨부·AI 설명 생성·**임시저장**을 보조하는 **Python Selenium RPA**로 구성됩니다. 최종 등록·공개는 자동 수행하지 않으며 담당자가 결과를 확인합니다.

## 주요 업무 흐름

1. 담당자가 웹 도구에 CSV를 업로드하고 분석 결과를 검토합니다.
2. 웹 도구에서 `등록자료.xlsx`를 내려받습니다.
3. 내부망 PC에서 Excel, 원본 CSV, 분류체계 DB를 준비합니다.
4. `internal-rpa/data_register.py`가 Excel의 미완료 행을 검증하고 포털 화면에 입력합니다.
5. 포털 **임시저장**이 확인된 행은 Excel B열에 `임시저장완료`로 기록합니다.
6. 담당자가 포털 목록과 Excel 기록을 대조합니다.

웹 도구의 한 번에 처리하는 CSV 수와 내부망 RPA가 처리하는 미완료 행 수는 별개의 개념입니다.

## 구성

- `server.mjs`: 로컬 Node.js 서버 진입점
- `dist/`: 웹 화면 정적 파일(서버 실행에 필요)
- `registration-*.mjs`, `application-*.mjs`, `public-data-helper.mjs` 등: 메타데이터 생성·Excel 작성 관련 모듈
- `test-*.mjs`: Node.js 테스트
- `internal-rpa/data_register.py`: 현재 기준 Python RPA
- `internal-rpa/README.md`: RPA 준비·실행·주의사항
- `.env.example`: 환경변수 예시(실제 인증정보 없음)

## 로컬 웹 실행

Node.js 20 이상이 설치된 개발 PC에서 프로젝트 최상위 폴더에서 다음을 실행합니다. 이 소스에는 `package.json`이 없으며, 서버 진입점은 Node.js 기본 모듈을 사용합니다.

```bat
node --env-file=.env server.mjs
```

로컬 주소: `http://127.0.0.1:8000`

AI 연동, 접속 비밀번호 등 일부 기능은 환경변수가 필요합니다. `.env.example`을 참고하되, **Node.js가 `.env` 파일을 자동으로 읽는다고 가정하지 마세요.** 실행 환경에 필요한 환경변수를 별도로 설정해야 합니다. AI 외부 서비스 연동은 유효한 승인 계정·네트워크·설정이 없으면 동작하지 않을 수 있습니다. 현재 등록용 폴더에서는 분류체계 파일 로딩과 Worker 빌드를 확인했습니다. 원본 목록의 공개 가능 여부는 GitHub 반영 전에 별도 확인합니다.

개발·시험 웹 주소: https://gyeongju-practice-20261006.cwhcom1130.chatgpt.site/ (현재 접속 및 배포 소스 일치 여부는 제출 전 재확인 필요)

## 내부망 RPA 실행

`internal-rpa/README.md`를 참조하세요. 내부망 전용 자료와 실제 포털 주소는 소스에 포함하지 않았습니다. RPA 실행에 필요한 `등록자료.xlsx`, `기관공유데이터_분류체계DB.xlsx`, CSV는 내부망 담당자가 별도로 준비합니다. **EXE 실행파일은 검증된 제출물로 제공하지 않습니다.**

## 보안 및 제출 범위

- `.env`, `.git`, 실제 업무용 Excel·CSV, 조직도 원본, 캐시, 실행기록, 과거 EXE 실험본은 제출 ZIP에서 제외했습니다.
- 조직도 검색 등 일부 선택 기능은 제외된 로컬 조직도 데이터가 없으면 제한될 수 있습니다.
- 시연은 승인된 합성자료로 진행하며, 실제 개인정보·계정·API 키는 제출하지 않습니다.
- 포털 임시저장과 최종 공개는 다릅니다. 오류 후 재실행 시 담당자가 포털 결과를 먼저 확인해야 합니다.

## 검증 상태

- Python RPA: **문법 검사 통과**, 실제 내부망 포털 동작은 별도 검증 필요
- Node.js: 테스트 결과는 `SUBMISSION-CHECK.md` 참고
- 웹 배포본과 제출 소스의 동일성 및 내부망 최종 RPA와의 차이: **최종 확인 필요**

이 ZIP은 **제출 준비본**입니다. 대회 신청서, 운영 가이드, 시연영상, GitLab 등록 및 최종 확인은 별도 진행해야 합니다.
